# 工作区界面

本地服务提供的原生 JavaScript 界面。UI 资源离线加载，没有前端打包步骤；安装 npm 依赖时生成 `vendor/` 下的 Markdown、净化和图标资源。

- `core/`：状态模型、请求边界、几何与展示函数。
- `features/`：按用户任务划分的控制器，如文件、画布、放置、连线、属性、仿真和对话。
- `app.js`：组合入口；`index.html` 与各功能 CSS：界面骨架及样式。

桌面文件夹是协作工作区，当前 `.circ` 决定画布和仿真对象，会话属于文件夹。元件放置的临时对象必须能立即参与选择和连线，同时保留原生失败后的恢复路径。仿真刺激不进入结构历史。

改动须通过用户可见的真实入口验证，尤其是鼠标命中、焦点、拖放、异步响应和窗口缩放。单独调接口不能证明这些交互可用。
