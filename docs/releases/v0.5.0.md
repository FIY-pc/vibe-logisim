# Vibe Logisim 0.5.0：更顺手的编辑与 AI 协作

本版改进电路编辑、仿真和 AI 对话，让操作反馈更明确，减少在设置和电路之间来回切换。

- **仿真跟随当前操作的电路**：浏览其他电路保留原有运行；在当前电路按运行、单步或操作输入，就直接启动对应仿真。进入运行中的子电路实例、返回根电路时保留同一份状态。启动与输入操作都有等待反馈。
- **布线可以分段完成**：拖线后在空白处松手即可落下一段，之后从线头继续。支持从空白起笔、折线和闭环；整理时保留未完成及独立导线的几何位置。
- **更清晰的编辑操作**：用 `1–4` 切换选择、布线、输入与平移，`A` 打开元件库；在“更多 → 快捷键”中查找、修改或恢复键位。撤销与画布工具放在一起，保存状态显示在文件名旁，`Ctrl+S` 直接保存。
- **模型选择更完整**：将服务返回的模型列表与公共模型资料合并展示，补充名称和能力；未知模型仍可手动配置。支持默认、轻度、中、高、极高、最高思考深度，具体选项依模型与接口支持而定。刷新失败保留已有列表与选择。
- **对话过程更易读**：保留真实工具输出和错误，清楚显示中断、结果未知与补充消息的加入状态；减少重复角色标签和界面说明。
- **修复工具参数兼容问题**：内置运行时通过 Responses 接口调用工具时，正确保留可选参数，避免不需要的字段干扰电路检查。

同一时间保留一个活动仿真；主动启动另一电路会替换原运行的临时状态，已留存的观察记录不受影响。自由画出的导线仍有电气含义，不是绝缘的标注框。

Windows x64 下载 `vibe-logisim-0.5.0-win32-x64-setup.exe` 后安装；Linux x64 下载 `vibe-logisim-0.5.0-linux-x64.tar.xz`，解压后运行 `vibe-logisim`。附件中的 `.sha256` 可用于校验下载文件。

内置运行时、Python 和 Java 继续随包提供，Codex 首次使用时自动下载。人工编辑与仿真无需连接 AI。
