# Vibe Logisim v0.2.1

面向第一批试用同学的 dogfooding 版本。这一版只做一件事：把「连上 AI」这一步做扎实。

## 下载

| 系统 | 文件 |
| --- | --- |
| Windows 10/11 x64 | `vibe-logisim-0.2.1-win32-x64.zip`，解压后双击 `vibe-logisim.exe` |
| Linux x64 | `vibe-logisim-0.2.1-linux-x64.tar.gz`，解压后运行 `./vibe-logisim` |

每个压缩包旁边有 `.sha256` 校验文件。首次运行 Windows 可能提示“未知发布者”，选“更多信息 → 仍要运行”。

## 这一版改了什么

**AI 设置重做**（右栏齿轮，或 AI 面板提示卡上的按钮）：

- 两个并列页签：**ChatGPT 账号** / **自定义接口**。没配置过时直接落在「自定义接口」页，不再把接口表单藏在折叠里；已登录 ChatGPT 或已保存接口时落在对应页签。
- 自定义接口：填好地址和密钥后自动读取接口的模型列表（可搜索、可键盘选择；接口不提供列表时可直接输入）。嵌入模型、语音、图像等不能对话的模型会从列表里去掉。
- **保存前先检测**：点「保存并连接」会先向接口发一条与实际请求同形状的流式测试请求。密钥无效、地址不对、模型名不存在、接口只支持 chat/completions、限流、服务端错误、超时——都在保存前用中文说清，并保留接口返回的原话。检测失败时可以「跳过检测直接保存」。
- 重新保存不必再输密钥（输入框提示已保存的密钥尾号，留空即沿用）。
- 接口读到的全部模型都进入输入框上方的模型选择器，可以直接切换；「思考深度」新增「关闭」档，给不接受推理参数的模型用。
- AI 面板提示卡同时给出「登录 ChatGPT」和「填写 API 接口」两个入口；面板文案不再出现「本机 Codex」。
- **读取系统代理**：Clash、v2rayN 等开启「系统代理」后（或设置了 `HTTPS_PROXY` 环境变量），ChatGPT 登录、OpenAI/中转接口的请求和保存前的检测都自动经过该代理。AI 设置右下角显示检测到的代理地址或「直连」，代理设置变化后提示「重新连接」；连不上时的错误提示会说明这次走的是代理还是直连。

**兼容性**：已保存的接口设置（provider.toml）无需重新填写，首次打开设置会按旧格式读出。

## 已验证

- 单元测试：接口探测（模型列表、Responses 试连、各类错误分型）、接口配置写入与读取（多模型目录、留空密钥沿用）。
- 真实 Electron 端到端（系统代理）：接口放在只有代理才能解析的域名后面，设置了 `HTTPS_PROXY` 的实例里模型发现、保存前检测和 Codex 子进程的真实回合都经过代理；未设代理的实例页脚显示「直连」，同一接口在保存前失败并提示开启系统代理。
- 真实 Electron 端到端（对着一个本地假 Responses 服务）：提示卡入口 → 错误密钥在保存前被拦下且未写盘 → 正确密钥自动列出模型 → 保存后 Codex app-server 连接成功、模型选择器列出接口模型 → 重开设置不重输密钥再保存 → 停用接口恢复。
- 打包冒烟见 `.github/workflows/bundle.yml`（Windows 上含两轮真实模型回合，走同一套设置界面）。

## 已知限制

- 自定义接口仍只支持 **Responses API**（Codex 0.15x 已移除 `wire_api = "chat"`）。只提供 `chat/completions` 的接口，保存前检测会明确指出。
- 代理只支持 HTTP 代理（Clash/v2rayN 的 HTTP 或混合端口）；纯 SOCKS 端口会在设置里提示「代理不支持」。带账号密码的代理：保存前检测会报代理要求认证，可「跳过检测直接保存」，AI 引擎本身能用。
- macOS 暂无安装包。其余同 v0.2.0。
