# Vibe Logisim 26.11.4

本次更新新增 macOS 预览包、单电路 AI 协作和聊天图片附件，并改进文件操作与 AI 中断后的恢复体验。以下变更相对于 26.11.3。

## 新增

- **macOS 预览包**：提供 Apple Silicon 和 Intel 两种架构的 DMG、ZIP，支持 macOS 13.5 及以上，内置 Java 和 Node.js。当前为开发签名，尚未完成 Apple 公证，首次打开可能受到系统安全限制。
- **单电路 AI 协作**：新建但未保存的电路、单独打开的 `.circ` 文件都可以直接与 AI 协作，无需先打开项目文件夹。编辑保留撤销、草稿恢复和显式保存；对话按电路隔离，保存、重开及重启后可以继续。
- **文件引用和图片附件**：在文件列表复制文件后粘贴到聊天框，即可创建引用。支持粘贴、选择或拖入 PNG、JPEG、WebP 图片，发送前可以预览、移除，也可以只发送附件。
- **欢迎页与最近项目**：提供新建电路、打开电路、打开项目文件夹入口，并保留最近 10 个项目。失效路径会显示提示，移除记录不会删除项目文件。

## 改进

- 文件列表支持复制、剪切、粘贴及对应快捷键；macOS 原生“编辑”菜单根据焦点执行文件操作或文本编辑。复制遇到同名文件时自动编号，移动和导入冲突提供明确的处理选项。
- 文件拖放时可在列表边缘持续滚动；批量导入支持对后续冲突应用相同选择。
- AI 执行过程与最终回答分区显示。过程可折叠为步骤摘要，耗时独立显示；失败或中断的过程文字不再被当作最终回答。
- 主动停止后，输入框为空时，发送按钮变为继续按钮；输入新内容后恢复正常发送。
- 尚未正式开放的课堂入口移至标题栏省略号菜单。

## 修复

- 网络中断、临时限流或服务异常时，在有限次数内自动重试失败的模型步骤，保留此前输出和已完成的执行记录。需要人工继续时，也不再先撤回整轮内容。
- API 密钥、权限、额度或模型配置错误会给出明确说明并引导检查 AI 设置，避免无效的重复重试。
- 修复工具调用中断后继续对话时，调用与结果配对错误导致请求失败的问题。
- 修复 macOS 高分屏下原生文件拖放位置偏移，以及输入框初次挂载或侧栏缩放时高度异常的问题。

## 升级说明

- macOS 包目前作为预览提供，尚未经过 Developer ID 签名和 Apple 公证。
- 图片附件单张上限为 8 MiB，需要选择支持图片输入的模型。
- 应用内更新检查仅提供提示，需要手动下载并安装。

| --- | --- | --- |
| Windows x64 | `vibe-logisim-26.11.4-win32-x64-setup.exe` | `vibe-logisim-26.11.4-win32-x64.zip` |
