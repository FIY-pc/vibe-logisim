# Vibe Logisim 0.6.0-beta.3：预览版第三轮

这是 0.6 系列的第三个预览版，也是最后一个 beta：编辑、仿真、整理布局和 AI 工具管道四条路径都按新设计重做了一遍。之后进入 rc，只修问题。0.5.0 的应用内更新提示仍不会指向预览版，需要手动下载。

## 改进

- **编辑即时响应。** 每次编辑的新修订从内存直接交给 Logisim 运行时，不再为每个修订落盘快照；元件和导线在窗口、宿主和运行时之间只用一套编号。1 MB 工程的 713 件页面上，移动、连线、放置、删除、改属性的宿主响应从 174 / 44 / 53 / 38 / 59 毫秒降到 19 / 12 / 15 / 13 / 18 毫秒。
- **移动元件照 Logisim 的规则。** 拖动时选中的对象跟着指针走，不等任何请求；松手由 Logisim 自己的移动逻辑决定加减哪些导线，一步撤销。拖到导线或端口上就接通，拖开仍保持连接，按住 Shift 拖动则断开；不再有"这个位置会改变连接，移动未应用"的拒绝。课程规模页面上从松手到新画面约 64 毫秒。
- **窗口自己画电路。** 编辑器画面由窗口用录制的元件符号绘制；平移缩放不发请求、不等待。仿真运行中只传变化的部分：启动到首画约 0.75 秒，整幅 110 KB，256 Hz 下每秒约 177 KB（之前 3 MB）。仿真运行状态只保留在 Java 进程里，页面刷新后画面照常回来。
- **整理布局换成分层图。** 整理器从电路网表建一张 ELK 分层图，输入在左、输出在右，按信号深度分列，在多种变体里选可读性最好的一种；跨区信号可以改用隧道。可读性分（越低越清楚）小电路：全加器 54.9→23.3、译码器 156.7→51.3；课程规模页面 11 页中 10 页更清楚，713 件的流水线页 2991→1206。
- **AI 跟着文件走。** 磁盘上的文件是文档的真相：AI 用脚本改了打开的工程，下一次操作就读到新内容；宿主对每次文档变化广播事件，窗口不再轮询。AI 的每次编辑回复带上新元件编号、位宽冲突和保存结果；提示和工具说明只写事实，体积缩小约三分之一。
- **AI 大改动可撤销。** 建子电路、放元件、连线、整理、仿真验证一气做完，对话卡片上一键撤销整回合，文件字节级回到之前。

## 已知限制

- 整理布局对"几个子电路实例加分线器"这类图（例如用四个全加器拼的加法器）还排不好：无参整理会把实例排成楔形、分线器到实例的线绕一大圈；分组整理后隧道标签可能互相重叠。
- 0.5.0 的应用数据不迁移：模型服务需要重新添加，旧的对话记录不会出现。
- Windows 原生拖放与回收站、更多元件库与插件、Ubuntu 24.04 以外的 Linux 发行版尚未充分验证。
- macOS 暂未提供安装包。

## 下载

| 系统              | 文件                                                                               |
| ----------------- | ---------------------------------------------------------------------------------- |
| Windows 10/11 x64 | `vibe-logisim-0.6.0-beta.3-win32-x64-setup.exe`（安装），或 `.zip`（便携）         |
| Linux x64         | `vibe-logisim-0.6.0-beta.3-linux-x64.deb`，或 `.tar.gz`（解压后运行 `./start.sh`） |

`SHA256SUMS` 可用于校验下载文件。Windows 未签名程序可能提示“未知发布者”，选择“更多信息 → 仍要运行”。建议先卸载 0.5.0 再安装；两者的设置互不影响。Linux 包基于 Ubuntu 24.04 构建，需要 GTK3 与 WebKitGTK 4.1。**人工编辑和仿真无需连接 AI。**
