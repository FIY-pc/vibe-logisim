# Vibe Logisim 0.6.0-beta.1：原生重写预览版

这是 0.6 系列的第一个预览版。应用从 Electron 和 Python 换成了 Rust 宿主、Tauri 窗口和 React 界面，电路的加载、绘制和仿真仍由 Logisim 本体负责。核心路径（打开工程、编辑、仿真、让 AI 修改、保存重开）已经走通，细节仍在打磨，所以先以预览版发布；0.5.0 的应用内更新提示不会指向它，需要手动下载。

## 和 0.5.0 的主要差别

- **AI 直接修改工作文件夹里的工程**：改动即时出现在编辑器中，每轮对话记录一次文件夹检查点，可以在对话里查看改动或整体撤销。不再有单独的“方案审阅 → 应用”步骤。
- **模型服务只需要接口地址、密钥和模型名**：支持流式 Chat Completions、Responses 和 Anthropic Messages，附带 OpenAI、DeepSeek、Anthropic、OpenRouter 预设。不再依赖 Codex 命令行或 ChatGPT 账号。
- **工作文件夹就是工作区**：左栏显示文件夹内容，可以预览文本、图片和 PDF 资料并在对话中引用；文件改动有历史，可以对照任意两个版本并恢复。
- **整理布局按结构识别**：寄存器与流水级由电路连接关系判断，不依赖元件或电路的名字；子电路的输入是否已寄存也按其内部网络计算。
- **编辑器**：元件移动时预览重连的导线，提交前核对端口连接不变；工具栏删除与 Delete 键一致；下拉列表由应用绘制，不再跟随系统主题。
- **安装包更小**：Windows 安装程序约 100 MB（0.5.0 为 160 MB），随包提供 Node.js 与 Java，不再包含 Python。

## 已知限制

- 在 1 MB 左右的大工程里，移动元件或连线需要 0.6–0.9 秒，正式版前会处理。
- 0.5.0 的应用数据不迁移：模型服务需要重新添加，旧的对话记录不会出现。
- Windows 原生拖放与回收站、更多元件库与插件、Ubuntu 24.04 以外的 Linux 发行版尚未充分验证。
- macOS 暂未提供安装包。

## 下载

| 系统              | 文件                                                                               |
| ----------------- | ---------------------------------------------------------------------------------- |
| Windows 10/11 x64 | `vibe-logisim-0.6.0-beta.1-win32-x64-setup.exe`（安装），或 `.zip`（便携）         |
| Linux x64         | `vibe-logisim-0.6.0-beta.1-linux-x64.deb`，或 `.tar.gz`（解压后运行 `./start.sh`） |

`SHA256SUMS` 可用于校验下载文件。Windows 未签名程序可能提示“未知发布者”，选择“更多信息 → 仍要运行”。建议先卸载 0.5.0 再安装；两者的设置互不影响。Linux 包基于 Ubuntu 24.04 构建，需要 GTK3 与 WebKitGTK 4.1。**人工编辑和仿真无需连接 AI。**
