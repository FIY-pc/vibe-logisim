页面：https://lovej.site/vibe-logisim/#demo 。代码发布提交：`ea74b56`，独立分支 `feat/showcase-comments`。

## 实现

首屏静态工作台升级为可选择提示词的引导演示，保留加载失败时的原工作台截图。三个预编排场景分别演示构建一位全加器、解释进位路径，以及验证全部输入组合。

- 构建流程包含需求输入、回答逐步呈现、元件出现、连线绘制、仿真切换及完成提示。
- 支持暂停/继续、重播、拖动进度、场景切换；空白起点和完成状态均可反向定位。
- 完成后可切换 A / B / Cin，回放对应输入的预录仿真图像与输出。
- 元件与连线复用桌面应用 `editor/paint.ts` 的实际 Canvas 绘制代码。录制脚本使用隔离的 Rust / Java Logisim host，对公开的全加器示例录制 10 个元件、32 条连线及全部 8 组状态，并逐组断言 Sum 与 Cout。
- 浏览器只加载静态脚本和录制数据；对话为预设脚本，不连接模型、本机 host 或课堂服务，不消耗模型额度。
- 桌面采用三栏工作台，手机将画布和对话上下排列。固定工作区高度，后台标签与离开演示区域时暂停，尊重减少动态效果偏好。
