# 数字电路工作参考

按当前问题读取，不需要每次通读。它们是设计线索，不是强制流水线或课程答案。

- [学科知识与设计选择](digital-design.md)：组合表示、时序状态、数据通路、教学约束，以及原始课程来源。
- design.circ 是可修改的完整工程，不限于空白模块。可以写脚本生成、改写、删除组件/导线、添加电路定义和子电路实例；先检查既有接口及所有调用方。
- materials/ 是用户提供的任务书、工作簿或图像。PDF 可用 pdftotext -layout 读取；需要图形时用 pdftoppm 配合图像工具。Excel 公式没有缓存不意味着结果为零。
- 使用 inspect_circuit 获得当前版本或候选的原生端口位置和连通。修改后的文件要先 submit_circuit 才成为工具可读取的候选。组件 ID 随版本变化。
- 如果使用 build_candidate 或 wire_candidate，先 checkout_candidate 才能在 design.circ 上继续它们的成果。不要无意用旧暂存文件覆盖新候选。
- submit_circuit 会原生加载并建立差异，但不会替你判断功能正确。simulate_circuit 是每个向量独立的组合传播；trace_circuit 是另起状态的时钟执行，不是用户屏幕正在运行的那一实例。
- 两种应用模式不改变可用的解题方法。最终应用由宿主完成；不要通过读写别的工程目录、网络 API 或伪造工具结果绕过审批。
- 保存有用的设计决定、脚本和引用，后续回合可复用。未知要求明确标注；不需要预先把所有事情形式化才开始构建。
