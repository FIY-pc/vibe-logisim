# Vibe Logisim 0.4.1：更容易开始使用 AI

本版加入内置 AI 运行时，并重新整理模型服务配置，让第一次连接与后续管理更直接。

- **内置运行时**：使用 API 密钥即可开始，支持 Chat Completions、Responses 和 Anthropic Messages。ChatGPT 账号仍可通过随包附带的 Codex 运行时使用。
- **模型服务管理**：保存多个服务、发现模型、检测连接，并为新对话选择默认服务。常用服务优先显示必要字段，自定义地址和协议按需填写。
- **统一会话列表**：每条对话保留自己的运行时和模型服务；更改默认设置不影响已有对话。更换已有对话的模型服务时，明确显示历史将发送到哪里。
- **中断更清楚**：保留已收到的回答和工具输出，标明结果未知的操作；重新打开后不会自动重复执行。

下载对应系统的完整压缩包，解压运行。Windows、Linux x64 包包含所需运行环境。人工编辑与仿真无需连接 AI；AI 需要自己的账号或接口额度。
