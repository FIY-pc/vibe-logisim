# 线上部署验收：2026-10-30

目标服务：`https://lovej.site/vibe-classroom`，发布代码 `bb2fd34`。使用临时教师、学生、独立课堂及服务器回环地址上的模拟模型，通过公网 HTTPS 验证；没有调用付费模型，也没有使用真实用户数据。

已通过：

- HTTPS 健康检查；Tauri 来源预检返回 204；未授权来源返回 403；未登录的课堂请求返回 401。
- 教师注册码校验、学生注册、课堂码加入、重复加入、人数上限；其他教师和未加入的学生不能读取课堂。
- 提交电路和交互记录、相同提交重试、冲突提交拒绝；教师查看全部成员、学生仅查看自己，不能读取其他学生的提交。
- 教师配置 AI、学生领取独立凭据、教师真实密钥不出现在配置响应中。
- 公网 HTTPS 模型代理；首段 SSE 在结束标记前收到，验证 Nginx 没有缓冲整个回答；项目实际使用的 AI SDK 能消费完整回答。
- 禁止调用未发布的模型、每名学生两个并发请求的上限、撤销凭据、停用及重新开放模型服务。
- 课堂码轮换使旧码失效；关闭课堂后拒绝提交和模型请求；重新开放后保留原提交。
- 退出登录后，登录令牌和课堂模型凭据均失效。
- 在确认不存在其他用户数据后重启服务，账号、课堂和提交保留。

限制：教师学情分析的服务端 `CLASSROOM_AI_*` 尚未配置，接口按预期返回 503。这次线上模型验证使用模拟 Chat Completions 服务，不代表具体付费服务或模型已通过兼容性验证；其他协议此前已在本地测试。

验收结束后，按测试运行生成的精确用户及课堂 ID 清理临时账号、成员、会话、提交和模型凭据，停止模拟模型服务。最终健康检查通过，systemd 服务保持 active。该轮验证没有发现线上接口和流式转发的阻塞性问题。
