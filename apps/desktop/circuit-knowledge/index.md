# 数字电路工作参考

按当前问题读取，不需要每次通读。它们是设计线索，不是强制流水线或课程答案。

- [学科知识与设计选择](digital-design.md)：组合表示、时序状态、数据通路、教学约束，以及原始课程来源。
- 工作目录就是用户打开的文件夹，`.circ` 是可修改的完整工程，不限于空白模块。可以写脚本生成、改写、删除组件/导线、添加电路定义和子电路实例；先检查既有接口及所有调用方。
- 用户提供的任务书、工作簿和图像是文件夹中的普通文件。按实际路径和可用文件工具读取；Excel 公式没有缓存不意味着结果为零。
- 使用 inspect_circuit 获得当前版本或候选的原生端口位置和连通。模型直接修改实际工作区中的 `.circ` 后，用 submit_circuit 刷新共享画布和 Studio 观察版本；它不会把文件变成候选，也不会替代行为验证。组件 ID 随版本变化。
- 如果使用 build_candidate 或 wire_candidate，checkout_candidate 会将成果写入当前选择的 `.circ`。继续在该文件编辑，避免用旧文件覆盖新候选。
- submit_circuit 会原生加载当前文件，但不会替你判断功能正确。simulate_circuit 是每个向量独立的组合传播；trace_circuit 是另起状态的时钟执行，不是用户屏幕正在运行的那一实例。
- 文件改动直接留在工作区，用户可随后查看和撤销。可选候选工具不限制直接编辑和其他解题方法。
- 保存有用的设计决定、脚本和引用，后续回合可复用。未知要求明确标注；不需要预先把所有事情形式化才开始构建。
