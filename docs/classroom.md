# 课堂与教师端

课堂服务是独立部署的 Node.js 24 服务，数据存储在 SQLite 中。学生和教师使用同一个工作台的“课堂”入口登录；原有电路编辑与仿真无需登录。服务不读取客户端磁盘。学生进入课堂后，客户端会自动同步绑定工作文件夹中的当前电路与当前 AI 对话，并持续显示同步状态。

## 启动服务

在仓库根目录运行（PowerShell）：

```powershell
$env:CLASSROOM_TEACHER_CODE = '设置一个仅发给教师的随机邀请码'
npm run classroom
```

默认监听 `http://127.0.0.1:8810`，数据库位于 `.classroom-data/classroom.sqlite`，不进入 Git。教师注册需要上述邀请码；学生注册需要姓名和学号。密码至少 10 个字符，服务保存 scrypt 哈希；登录令牌在服务器只保存哈希，12 小时过期，可主动退出。

教师注册后创建课堂，填写任务、评价标准和人数上限，取得课堂码。之后可在“课堂设置与 AI 服务”中修改名称、任务、评价标准和人数上限；人数上限不能低于已加入人数。学生填写同一服务地址，注册后使用课堂码加入。课堂码泄露时，教师可点击“更新课堂码”，旧码立即失效，已加入的学生和历史提交保留。教师也可以关闭课堂，此后不能加入或提交；重新开放后恢复。

多台电脑连接时设置 `CLASSROOM_HOST=0.0.0.0`，并让客户端填写教师服务器的实际地址。跨网络部署应使用 HTTPS 反向代理；把浏览器界面的实际来源加入 `CLASSROOM_ORIGINS`（英文逗号分隔）。默认允许开发页面 `http://127.0.0.1:5173`、`http://localhost:5173` 和 Tauri 的本地来源。

| 环境变量 | 含义 |
| --- | --- |
| `CLASSROOM_HOST` / `CLASSROOM_PORT` | 监听地址 / 端口，默认 `127.0.0.1` / `8810` |
| `CLASSROOM_DATABASE` | SQLite 路径 |
| `CLASSROOM_TEACHER_CODE` | 教师注册邀请码；未设置时禁止注册教师 |
| `CLASSROOM_ORIGINS` | 允许访问服务的页面来源；设置后替换默认列表 |
| `CLASSROOM_AI_BASE_URL` | Chat Completions 兼容接口前缀，例如 `https://provider.example/v1` |
| `CLASSROOM_AI_API_KEY` | 服务端 AI 密钥 |
| `CLASSROOM_AI_MODEL` | 分析使用的模型 |

AI 三个变量必须一起配置；重启服务后生效。密钥不返回客户端，也不写进分析报告。没有配置 AI 时，账号、课堂和审阅功能仍可使用。

## 学生自动同步

学生注册并使用课堂码加入，选定课堂后自动绑定当前工作文件夹。客户端每 15 秒检查当前电路与当前 AI 对话的变化，无需勾选共享，也无需填写自报进度或说明。当前课堂绑定保存在本机，重开应用且登录令牌有效时继续同步；关闭课堂窗口不会停止。

切换同一文件夹的电路或 AI 对话会自动跟随；切换到其他工作文件夹，或者打开绑定文件夹外的电路时暂停，避免传输其他项目。可点击“绑定当前工作文件夹”重新绑定。退出登录停止同步。界面明确显示同步范围、时间和错误；网络恢复后自动重试。AI 回合进行中会等待结束再抓取一致的问答。

“立即同步”可手动触发检查，“提交电路”会记录一次正式提交；后续修改仍自动同步。修改后的新快照重新显示为学习中。已提交不代表通过功能判题。

快照保存电路 XML、主电路 PNG、修订、元件与导线数量，以及当前对话的问答与工具结果。每次保留最近最多 1000 条、单条最多 20000 字、正文总量最多 500000 字；超长记录明确截断。不会读取模型配置、个人 API 密钥或其他文件内容；识别出的密钥样式会在交互文本中脱敏。历史快照仍保留此前同步过的其他课堂对话。

电路 XML 上限 8 MB（原 2 MB 无法容纳真实 CPU 实验文件），PNG 上限 1 MB，JSON 请求及解压后上限 12 MB。大请求使用 gzip 传输，服务器按电路内容去重存储 XML 和图像，避免每次聊天变化重复存储大电路。当前不打包第三方元件库，教师预览使用学生端图像，XML 保留原工程引用。

不再展示自报完成百分比和进度说明。教师输入输出测试用例判题尚未实现：本机已有隔离仿真向量能力，但服务端需增加受限的 Java 仿真环境、引脚映射、时钟与复位规则、超时和外部库隔离，才能把结果作为可靠的通过/未通过证据。

## 教师分发 AI 配置

教师在“课堂设置与 AI 服务”中新建模型配置，填写名称、接口地址、协议、API Key、模型、上下文窗口和思考深度。“保存并用于本课堂”会将配置加密存入本人模型库，并应用到当前课堂。其他课堂可直接从“教师模型库”选择，无需重复输入密钥；现有课堂配置自动迁入模型库。模板和密钥仅配置所属教师可以使用。

修改模型库配置再应用，只更新当前课堂，其他课堂保持原配置，可另行应用。支持 Chat Completions、Responses 和 Anthropic Messages；编辑时密钥留空保留原值，更换地址或协议需重新填密钥。可以单独暂停学生使用或撤销学生凭据。

API Key 仅能填写在密钥栏：模型名称、服务名称和地址中检测到密钥会拒绝保存；历史误填元数据也会在公开响应和本机设置中脱敏。学生端课堂服务不可编辑上游地址或真实密钥；服务列表按课堂命名，减少同名模型混淆。

学生在“AI 服务来源”点击“使用教师提供的 AI”，将配置加入本机并绑定当前对话。也可点击“管理自己的 AI 配置”添加个人服务，或刷新后选择个人服务并点击“使用自己的 AI”。切换不会删除另一种配置，个人密钥仅保存在学生本机。需先打开工作文件夹并等待当前 AI 回合结束。

教师真实密钥不会分发到学生电脑：服务器使用 AES-256-GCM 加密保存密钥，为学生签发独立课堂凭据并代理流式模型请求，只允许使用教师发布的模型和协议。使用费用计入教师的模型服务账号；当前不提供学生 token 配额或计费统计，每名学生最多同时发起两个代理请求。

教师更新密钥后，后续请求使用新密钥。模型或协议变化后，学生需重新启用教师配置。教师可撤销全部学生凭据，关闭课堂或取消开放也会阻止后续请求。学生重新领取凭据会使旧凭据失效，退出课堂账号会撤销该学生的课堂 AI 凭据。此配置用于学生对话；教师“AI 学情分析”仍使用服务端 `CLASSROOM_AI_*` 配置。

数据库旁自动生成 `<数据库文件>.ai-key`，例如 `classroom.sqlite.ai-key`，它是恢复教师密钥所必需的加密密钥文件，应与数据库一起安全备份，不能提交到 Git。已有配置时若该文件缺失，服务会拒绝启动并要求恢复备份。

## 教师审阅和 AI 分析

教师仅能查看自己创建的课堂。学生仅能看到自己在课堂中的提交；课堂列表、提交历史和分析接口都由服务器检查角色及课堂归属。教师审阅为只读，不修改学生电路。

教师看板每 15 秒刷新学生状态，显示学习中/已提交、最近同步时间、元件/导线数量、提问数和工具错误数。选择学生后可查看最近 50 次提交、图面、XML 和问答。

教师点击“生成分析报告”才调用服务端模型；自动同步、教师刷新和用量预览不会调用模型。分析使用课堂任务、评价标准、最新快照统计和有长度预算的问答摘录，并引用提交证据编号。全班默认只发送问题、回答与错误摘要，不发送完整 XML；选择单个学生时补充较详细的问答和最多 3500 字电路摘录。

全班整个序列化提示预算为 24000 字符，单人 14000 字符，包含系统指令和 JSON 开销；最多输出 1800 tokens。超出预算的记录会摘录或省略，预览与报告明确显示覆盖人数。界面显示基于 UTF-8 长度的输入 token 估算，实际用量在模型返回 usage 时记录并展示。token 估算不是模型 tokenizer 的精确计数。

相同模型、证据、课堂任务和问题会复用最近保存的相同报告，不再发起模型请求。报告保存模型、时间、覆盖人数与证据编号。界面每次只分析一个课堂或选中的学生，不能把缺失与截断的记录当成完整证据。

进度和图像由客户端提供，服务没有运行学生电路，不能视为考试防作弊系统或自动正确性判分。AI 被要求区分证据与推测，未同步不代表未学习，也不能仅凭 AI 使用频次认定作弊。

## 数据与开发

账号、成员、不可变提交快照和报告持久化到 SQLite，开启外键和 WAL。备份应在停止服务后复制数据库，或使用 SQLite 在线备份工具，不能只复制运行中的主文件而遗漏 WAL。当前版本不提供找回密码、批量导入、学校 SSO 或自动评分；课堂历史由部署方按课程留存政策管理。

```sh
npm run test:classroom
npm run test:ui
npm run check
```

课堂测试使用真实本地 HTTP 服务、临时 SQLite 和模拟模型接口，覆盖账号、角色、课堂隔离、容量、幂等提交、持久化和 AI 证据范围。UI 测试验证默认自动同步、超过 2 MB 的电路、对话切换、跨文件夹暂停、敏感配置过滤、课堂编辑、模型库复用、教师审阅与分析报告。

设计参考 [AES](https://github.com/pixelnova20/aes) 的 `courseworks` 模块（参考提交 `e6a5634d5d70039c9582ef04901a5bcc0915ce05`）：课堂邀请码、按教师及课堂校验访问、只读审阅和证据驱动分析。本实现使用独立账号与存储，不连接 AES 生产系统，也未复制其源码。
