# Vibe Logisim v0.2.0

第一个面向同学公开的版本。解压即用，不需要装 Java、Python 或任何东西。

## 下载

| 系统 | 文件 |
| --- | --- |
| Windows 10/11 x64 | `vibe-logisim-0.2.0-win32-x64.zip`，解压后双击 `vibe-logisim.exe` |
| Linux x64 | `vibe-logisim-0.2.0-linux-x64.tar.gz`，解压后运行 `./vibe-logisim` |

每个压缩包旁边有 `.sha256` 校验文件。首次运行 Windows 可能提示“未知发布者”，选“更多信息 → 仍要运行”。

## 能做什么

- 打开课程文件夹，直接编辑课程的 `.circ`（兼容 HUST 2020 版 Logisim 和 Logisim-ITA 2.16），文件可以随时用原版 Logisim 打开核对。
- 画电路：搜索放置元件、端口连线、`P` 操作输入看信号、`Ctrl+T` 启停仿真、`Ctrl+Z` 撤销、文件树拖动、改动查看与撤销。
- AI 协作：右栏描述需求，AI 直接读写你文件夹里的电路，能观察结构、跑真值表、渲染图片来检查自己的结果。
- 连接 AI 的两种方式：登录 ChatGPT；或在「AI 设置 → 使用自己的 API 接口」填写任意 OpenAI 兼容接口（需支持 Responses API）的地址、密钥和模型。密钥只保存在本机。

## 已验证

- Windows 和 Linux 安装包都在真实系统上跑通：打开文件夹 → 新建电路 → 放置与门和引脚 → 连线 → 用内置 Java+Logisim 跑四组真值 → 关闭重开。
- 通过 API 接口的真实模型回合：在打开的空电路里构建全加器，模型用结构化工具放置和连线，自行仿真 8 组输入全部通过。

## 已知限制

- macOS 暂无安装包。
- AI 接口只支持 Responses API；只提供 `chat/completions` 的接口目前不能用。
- Windows 上 AI 进程由 Codex 的 workspace-write 沙箱限制（只能写打开的文件夹和应用配置目录）；Linux 上由 systemd 隔离。
- 大型课程电路（如完整 CPU）的 AI 自动构建仍不稳定；AI 更适合讲解、检查、局部修改和小模块构建。
