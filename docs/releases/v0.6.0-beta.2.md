# Vibe Logisim 0.6.0-beta.2：预览版第二轮

这是 0.6 系列的第二个预览版：修复 beta.1 的一个阻断问题，并完成第一轮打磨。0.5.0 的应用内更新提示仍不会指向预览版，需要手动下载。

## 修复

- **仿真无法启动**：beta.1 里仿真菜单、工具栏按钮和快捷键（Ctrl+K、Ctrl+T）都启动不了仿真，已修复。

## 改进

- **对话面板**：每个问题一组。运行中逐步显示思考、回答和工具步骤；结束后折成一行摘要（耗时、改动的文件），回答和撤销卡片留下；失败或手动停止以一行结束。
- **菜单与控件**：所有 ··· 菜单、右键菜单、下拉列表和提示由应用自己绘制：弹层跟随触发按钮、不再被侧栏裁切、点击外部关闭、键盘可达，提示里带快捷键。
- **大工程编辑延迟**：1 MB 工程里移动元件、连线、改属性到新图画出，从 0.6–0.9 秒降到约 0.1 秒；打开并绘制整个工程约 4 秒。
- **AI 大改动**：AI 可以在工程里放元件、连线、移动元件并整理布局。整理结果先在 Logisim 运行时核对网表，一致才写入文件；每次工具调用是一个撤销步；回合内新建的文件随回合一起撤销。
- **整理布局**：门级小电路按信号流重新摆放：输入在左、输出在右、门按信号深度分列，平行导线隔开，导线不再穿过元件或擦过无关端口。可读性不再只数交叉，还看拐弯、近距平行、导线擦端口、导线压元件、标签压线、标签重叠、元件重叠、引脚朝向和线长；AI 和编辑器的整理只在结果比现在清楚时才应用，否则说明哪些方面会变差，文件不动。
- 对话记录在回合运行中按节流保存，工具步骤之间不再停顿。

## 已知限制

- 整理布局对靠隧道绘制的中等规模电路（约 80–300 个元件）通常排不出更清楚的结果，会保持原样；每个输入都扇出到所有门的电路（如译码器）整理后交叉仍然较多。
- 0.5.0 的应用数据不迁移：模型服务需要重新添加，旧的对话记录不会出现。
- Windows 原生拖放与回收站、更多元件库与插件、Ubuntu 24.04 以外的 Linux 发行版尚未充分验证。
- macOS 暂未提供安装包。

## 下载

| 系统              | 文件                                                                               |
| ----------------- | ---------------------------------------------------------------------------------- |
| Windows 10/11 x64 | `vibe-logisim-0.6.0-beta.2-win32-x64-setup.exe`（安装），或 `.zip`（便携）         |
| Linux x64         | `vibe-logisim-0.6.0-beta.2-linux-x64.deb`，或 `.tar.gz`（解压后运行 `./start.sh`） |

`SHA256SUMS` 可用于校验下载文件。Windows 未签名程序可能提示“未知发布者”，选择“更多信息 → 仍要运行”。建议先卸载 0.5.0 再安装；两者的设置互不影响。Linux 包基于 Ubuntu 24.04 构建，需要 GTK3 与 WebKitGTK 4.1。**人工编辑和仿真无需连接 AI。**
