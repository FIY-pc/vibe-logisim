# Vibe Logisim 26.11.1

本次更新新增 ChatGPT 订阅登录、课堂关卡评测和成绩管理，改进长对话处理、布局整理及 Windows 分发。以下变更相对于 0.6.0-beta.3。

## 新增

- 支持登录 ChatGPT 账号使用订阅额度，并可在 AI 设置中切换账号、查看用量或退出登录。自定义 API 服务继续支持独立配置和切换。
- 新增课堂协作。教师可以创建课堂、发布任务、查看学生同步的电路与学习记录，并生成班级或单人分析报告。
- 新增课堂关卡。教师可以发布图文说明、电路模板、分值及公开或隐藏测试用例；学生可以下载模板、提交电路并查看评测结果。
- 新增教师成绩表，支持查看各关完成情况、提交历史、总分和复制 CSV。
- 支持教师分发 AI 服务配置，学生可以在教师服务与个人服务之间切换。

## 改进

- AI 输入区新增上下文用量圆环，悬停可查看用量；接近容量上限时自动压缩较早的对话内容，保留本地完整记录并继续执行任务。
- 取消统一的 8K 输出限制，改用模型支持的输出容量或用户配置；不再静默裁剪用户设置的上下文容量。
- 移除布局整理的固定 60 秒超时，支持主动停止；命令工具允许指定更长的执行时间。
- 改进由重复子电路实例组成的布局，减少部分进位链的绕线；分组标题随元件移动，部分隧道标签会避让导线。
- 单次仿真支持的测试向量从 256 组增加到 1024 组。
- 调整 AI 设置入口，将 ChatGPT 订阅和自定义 API 放在同一列表；账号信息与用量管理集中在设置中。

## 修复

- 修复 Windows 便携包因内部路径过长而无法解压的问题。
- 修复 Windows 部分路径下无法下载课堂电路模板的问题。
- 修复课堂评测拒绝含文字注释或自定义外观的正确组合电路的问题。
- 修复单人分析包含其他学生成绩的问题。
- 修复班级分析在输入较长时丢弃整张成绩表或遗漏部分学生的问题；现在优先保留分数汇总，并标明省略的明细。
- 更新网络、归档及 AI 运行时依赖，修复相关已知漏洞。

## 升级说明

- 从本版起采用“年.月.当月发布序号”，`26.11.1` 表示 2026 年 11 月的第 1 次发布。常规更新不再使用 beta 或 rc 后缀。
- 0.6.0-beta 系列不能正确提示后续版本，请从本页手动下载并安装。应用的更新检查只提供提示，不会自动下载安装。
- 从 0.5.0 升级时，需要重新配置模型服务；旧版对话记录不迁移。已有 `.circ` 工程可继续打开。
- 课堂评测目前支持组合逻辑，不支持寄存器、时钟等时序电路。课堂服务需要同步更新，才能使用新增的关卡和成绩功能。
- ChatGPT 订阅功能是否可用、可选模型及用量额度以账号授权结果为准。
