# Vibe Logisim 26.11.2

本次更新重构资料阅读与工作区界面，新增会话批量导出和 Windows AI 脚本执行，并修复元件工具、导线编辑及课堂评测中的问题。以下变更相对于 26.11.1。

## 新增

- **PDF 阅读与引用**：支持连续阅读、全文搜索、页码跳转和阅读位置恢复；可引用选中的原文、整页或框选区域，点击对话中的引用可返回来源。AI 可按需搜索、读取后续页面，并查看扫描页图片。
- **会话批量导出**：从会话历史或对话操作菜单进入导出，搜索并勾选当前工作区的历史会话，包含已归档会话。导出为 ZIP，每条会话分别提供 Markdown 和 JSON 文件。
- **Windows AI 脚本执行**：AI 可通过 PowerShell 执行命令，使用应用附带的 Node.js 和 Java 运行生成、检查脚本，支持中文路径与 UTF-8 输出。
- **关闭工作区**：可从顶部“更多”或文件夹菜单关闭当前工作区。未保存文档会先提示保存、放弃或取消；关闭时停止 AI 回合、保存改动记录，并关闭电路和资料标签。重新打开后仍可查看历史会话与撤销记录。

## 改进

- 电路、PDF、图片和笔记使用同一组文档标签。默认单文档查看，可手动开启并排；切换标签保留阅读位置与当前子电路。
- Markdown 支持渲染预览与源码切换，识别 `.md` 和 `.markdown` 文件。
- 统一工作区的字号、颜色、控件尺寸、菜单和弹窗样式，调整分栏拖动与窄窗口布局。对话输入区的引用和正文分别滚动，发送操作保持可见。
- XML 源码编辑和历史对照使用新的编辑器，支持语法高亮、搜索和差异定位；长对话按需渲染屏幕附近的消息。
- 取消单条消息最多 8 条引用的数量限制。引用失败时在草稿内显示原因，可重试或取消，并保留已添加的引用和输入文字。

## 修复

- 修复 AI 设置窗口高度异常、长表单无法完整查看的问题。
- 修复新建工程缺少基础库导致文字元件不可用的问题，补齐字体属性的查询、放置、修改和保存支持。
- 元件查询可列出当前工程实际可用的元件；批量编辑失败时指出具体项、元件和位置，便于 AI 修正参数。
- 修复直线导线被不可见的中间点拆成多段的问题。选择、拖动和删除按连续直线处理，并保留拐角、分支与元件端口边界。
- 修复鼠标点击标签等控件后残留多余焦点框的问题，同时保留 Tab、方向键等键盘操作的焦点提示。
- 修复课堂试评在并发请求、慢上传及关卡更新时的状态错误；统一成绩表排序，修正模板引脚识别，并避免 CSV 中的文本字段被表格软件解释为公式。

## 升级说明

- 使用课堂功能时，请同步更新课堂服务。
- Windows 上的 AI 命令以当前用户权限执行，工作目录为当前工程，不提供文件系统隔离。
- 应用内更新检查仅提供提示，需要手动下载并安装。更早版本的迁移说明见 [26.11.1 发布说明](https://github.com/FIY-pc/vibe-logisim/releases/tag/v26.11.1)。
