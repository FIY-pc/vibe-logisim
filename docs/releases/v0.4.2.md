# Vibe Logisim 0.4.2：更轻的安装包

本版缩小下载与安装体积，让首次安装更快。内置 AI 运行时、Python 和 Java 继续随包提供，人工编辑与仿真无需额外下载。

- **下载包缩小一半以上**：Windows 从约 391 MB 降至 161 MB，Linux 从约 363 MB 降至 172 MB。
- **Codex 按需下载**：首次使用 Codex（包括 ChatGPT 登录）时自动下载，显示实际进度，支持取消和重试。安装后重启可直接复用；下载失败不影响编辑、仿真和查看历史会话。
- **Windows 安装程序**：支持选择安装位置、开始菜单入口、覆盖安装和卸载；卸载保留账户与会话数据。
- **会话保持统一**：切换运行时仍能查看已有会话，各条会话保留原来的运行时和模型服务。

Windows x64 下载 `vibe-logisim-0.4.2-win32-x64-setup.exe` 后安装；Linux x64 下载 `vibe-logisim-0.4.2-linux-x64.tar.xz`，解压后运行 `vibe-logisim`。附件中的 `.sha256` 可用于校验下载文件。

以上体积为主安装包，不包含首次使用时下载的 Codex。AI 功能仍需自己的账号或 API 接口及相应额度。
