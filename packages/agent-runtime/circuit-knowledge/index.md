# 数字电路工作参考

按当前问题读取，不需要每次通读。它们是设计线索，不是强制流水线或课程答案。

- [学科知识与设计选择](digital-design.md)：组合表示、时序状态、数据通路、教学约束，以及原始课程来源。
- [原生运行与独立 Java 检查](java-runtime.md)：工具实际使用的 JAR、CLI 语义、引脚 API 和进程退出；按需读取。
- [电路组织 skill](skills/circuit-organization/SKILL.md)：完整建图、扩展和整理时的功能分组、连接表示与图面检查；普通课设构建也适用，不必等用户另提整理。局部逻辑修复只检查受影响区域。
- 工作目录就是用户打开的文件夹，`.circ` 是可修改的完整工程，不限于空白模块。可以写脚本生成、改写、删除组件/导线、添加电路定义和子电路实例；先检查既有接口及所有调用方。
- 用户提供的任务书、工作簿和图像是文件夹中的普通文件。按实际路径和可用文件工具读取；Excel 公式没有缓存不意味着结果为零。
- 使用 inspect_circuit 获得当前版本的原生端口位置和连通。用脚本或 write_file 直接改写工作区中的 `.circ` 后，应用会重新载入它，再用 inspect_circuit 读取新版本；载入成功不代表行为正确。元件 ID 由位置决定：未移动的元件保持原 ID，移动或删除后旧 ID 失效；导线 ID 按文件顺序编号，增删导线后重新读取。
- place_component、connect、set_attributes、move_components、delete_objects 和 arrange_circuit 直接修改当前文件并立即生效，用户在画布上同步看到；做错了用 undo_edit 撤回最近一步。继续在该文件上编辑，不要用旧的生成文件整体覆盖它。
- simulate_circuit 是每个向量独立的组合传播；trace_circuit 是另起状态的时钟执行，不是用户屏幕正在运行的那一实例。
- 文件改动直接留在工作区；每个回合记录一次文件夹检查点，用户可随后查看和撤销。电路工具不限制直接编辑和其他解题方法。
- 保存有用的设计决定、脚本和引用，后续回合可复用。未知要求明确标注；不需要预先把所有事情形式化才开始构建。
